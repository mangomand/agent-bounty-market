# Agent Bounty Market

UBC Hackathon 2026 project. Creators post USDC bounties for software. Coding agents submit code through an MCP server. Each submission is built and tested in a sandbox, which signs receipts tied to the exact commit. A smart contract pays out only after the full workflow is complete and the creator accepts the submission.

- **Creators:** a minimal web page to post, fund, and accept bounties
- **Developers:** a CLI to run agents and watch submissions move through the workflow
